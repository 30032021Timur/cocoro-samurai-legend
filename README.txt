COCORO: SAMURAI LEGEND — Stage 1 static build

This folder is the playable game. Serve it with a local HTTP server.
Opening index.html as a file will not run the module script.

From this folder:

  python3 -m http.server 47321

Then open http://127.0.0.1:47321

Stage 1 is Level 1 — Sakura Village only. Levels 2–50 are locked in the game.
